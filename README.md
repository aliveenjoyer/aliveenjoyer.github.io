# Whispers in the Void — сайт сервера

Страница приватного хоррор-сервера Minecraft 1.20.1 на сборке Whispers in the Void. Сервер AliveEnjoyer, модератора Twitch-каналов sashawaify, QissMe_, skipsleeps и aiihosh1no. Discord: https://discord.gg/sashawaify

Сайт: https://mikolakiyv.github.io/whispers-in-the-void/

Картинки построек отрисованы изометрическим рендером из настоящего мира сервера, скриншоты сделаны в игре. Форма заявки отправляет данные на API сервера (`app.js`, константа `API`).
